# Code of Conduct

## The short version

Be decent. Argue with the work, not with the person doing it.

## What is expected

- Assume the other person is trying to build something good.
- Criticise the code, the claim or the mechanism — never the author.
- When you say something is wrong, say what would make it right.
- Accept that "I was wrong" is a normal sentence and costs nothing.

## What is not acceptable

Harassment, personal attacks, insults, discrimination on any basis,
sustained disruption, publishing someone's private information, and
unwelcome attention of any kind. This holds in issues, pull requests,
discussions, commit messages and anywhere else this project is discussed.

## Reporting

Report a problem privately to the maintainer through
[GitHub](https://github.com/jjanczur) — direct message, or a security
advisory on this repository if you would rather it stay out of the issue
tracker entirely. Reports are read by the maintainer alone and are not
discussed publicly without the reporter's agreement.

## Enforcement

The maintainer may edit or delete comments, close threads, or block an
account, in proportion to what happened and with a reason given. Behaviour
that continues after a warning ends in a ban.
